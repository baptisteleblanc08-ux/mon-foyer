Sauvegarde intégrale de Mon Budget

Version 1.7

Un seul fichier JSON reprend les comptes, opérations manuelles, mouvements bancaires et leurs validations individuelles, projets, règles de classement et, s'il est chargé, l'ancien budget 2009. Il permet de reprendre le travail sur un autre ordinateur.

La sauvegarde inclut tes catégories personnalisées et les propositions préparées à partir de tes validations. Les données restent dans ce navigateur ; aucune synchronisation OneDrive n'est activée.

Confidentialité : le JSON n'est pas chiffré. Conserve-le dans un dossier privé et sécurisé. La restauration remplace les données actuellement présentes, uniquement après confirmation.

Sauvegarde et restauration

Exporte une sauvegarde JSON pour ne pas dépendre uniquement de ce navigateur. Le fichier contient tes opérations et soldes : conserve-le dans un endroit privé. L'import remplace les données locales.
